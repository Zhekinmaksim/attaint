# Attaint mark

An angular A with an open gate in its crossbar. The mark uses the site's ink
(`#0C0D0C`) and paper (`#FAFAF7`) colours. Keep the square silhouette and the
central gap; do not stretch or add shadows.

- `logo.svg`: scalable master, 64 × 64 viewBox.
- `logo.png`: 512 × 512 PNG for the GenLayer Project Explorer application.
- `favicon.svg`, `favicon.ico`, and the 16/32 px PNGs: browser icons.
- `apple-touch-icon.png`: 180 × 180 home-screen icon.

Public downloads: https://attaint.xyz/logo.svg and https://attaint.xyz/logo.png.
