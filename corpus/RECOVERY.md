# Восстановление отозванных версий

Прогон 4 сентября 2026. Воспроизводится `probes/recover_pins.py` и
`probes/recover_sources.py`, сырые данные — `corpus/recovered-pins.json`.

## Что удалось

Пин отозванной версии переживает отзыв в чужих лок-файлах. `package-lock.json`
и `yarn.lock` записывают URL тарбола вместе с `integrity`, и эта запись остаётся
после того, как реестр перестаёт отдавать сам тарбол.

| версия | статус | независимых репозиториев |
|---|---|---:|
| `event-stream@3.3.6` | STRONG | 30 |
| `flatmap-stream@0.1.1` | STRONG | 29 |
| `node-ipc@9.2.2` | STRONG | 30 |
| `node-ipc@10.1.1` | FAIR | 2 |
| `ua-parser-js@0.7.29` | WEAK | 1 |
| `ua-parser-js@0.8.0` | нет | 0 |
| `ua-parser-js@1.0.0` | нет | 0 |
| `coa@2.0.3` | нет | 0 |
| `rc@1.2.9` | нет | 0 |

Расхождений между источниками ни по одной версии нет: там, где найдено больше
одного репозитория, все они называют одно и то же значение.

**Восстановимость обратна скорости реакции.** `event-stream@3.3.6` прожил в
реестре около двух с половиной месяцев и осел в тридцати лок-файлах.
Версии `ua-parser-js` сняли за несколько часов, и их почти никто не успел
залочить. То есть метод работает ровно на тех инцидентах, которые долго не
замечали, и отказывает на тех, что закрыли быстро.

### Первый прогон был неправ

Стоит записать, потому что это тот же класс ошибки, который проект собирается
ловить. Первая версия скрипта выдала для `ua-parser-js@0.7.29` значение
`sha512-demo`, взятое из файла-образца, и объявила «два согласных источника» для
`node-ipc`, хотя оба лежали в одном репозитории в папке с фикстурами.

Исправлено тремя правилами: голоса считаются по репозиториям, а не по файлам;
пути с `fixtures`, `samples`, `demo`, `__tests__` отбрасываются; значение
проверяется на формат — `sha512-` плюс 88 символов base64. Ровно эти же три
проверки нужны в контракте, когда челленджер приносит «доказательство».

## Чего не удалось

**Байты не восстановимы.** Тарболы отозванных версий отдают 404 и в npm, и на
зеркале yarn — зеркало проксирует тот же реестр.

Закоммиченные копии `node_modules` тоже недоступны: GitHub исключает
`node_modules` из индекса поиска по коду. Проверено — запрос
`path:node_modules/lodash filename:package.json` даёт ноль, тот же запрос без
фильтра пути даёт 674 тысячи.

Значит восстановленный `integrity` не с чем сверять. Он остаётся числом, которое
подтвердит архивную копию, если она найдётся, и не подтверждает ничего сейчас.

## Три уровня evidence

Отсюда следует, что у конверта должен быть уровень, и вердикт обязан его
учитывать.

**Уровень 1 — реестровый пин.** Оба тарбола скачаны, байты сходятся с
`integrity`. Судятся все классы. Работает для живых версий, включая
`event-stream 3.3.4 → 3.3.5`.

**Уровень 2 — лок-файловая реконструкция.** Тарбола нет, есть `integrity` и
граф зависимостей из N независимых лок-файлов. Судятся только те классы, которые
видны в этих данных. `INSTALL_HOOK`, `OPAQUE` и `LICENSE_SHIFT` на этом уровне
недоступны — им нужен тарбол, и вердикт по ним обязан быть `INCONCLUSIVE`, а не
`CLEAN`.

**Уровень 3 — ничего.** `INCONCLUSIVE` без вариантов.

Уровень пишется в конверт и в стейт. Вердикт `CLEAN`, полученный на уровне 2,
без пометки уровня — это ложь о том, что было проверено.

## Что это добавляет в спеку

Лок-файлы, залочившие `event-stream@3.3.6`, записали и его зависимости. Там
видно то, ради чего всё затевалось:

```
event-stream 3.3.6 -> flatmap-stream ^0.1.0
```

Патч-релиз добавляет новую зависимость, которой не было в 3.3.5, от автора без
истории. Это и есть атака, целиком, и она судима на уровне 2 без тарбола.

В словаре из раздела 3 спеки такого класса нет. Раздел 7 прямо выносит
транзитивные зависимости за скобки MVP. При этом самая известная атака на npm —
именно добавление зависимости, и это единственный громкий инцидент, который
удалось реконструировать.

Предлагаю добавить седьмой класс:

### `DEP_ADDED`
Объяснимо ли появление новой зависимости в этом обновлении. Патч-релиз,
добавляющий пакет, которого не было, от публикующего без истории — не то же
самое, что минорный релиз, добавляющий известную библиотеку с объявленной целью.
Судится по графу из конверта, тарбол не требуется.

Класс дешёвый, работает на уровне 2, и без него корпус остаётся без своего
главного кейса.
